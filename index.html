    What the WCAG levels require

    AA is the level most accessibility standards and policies ask for. AAA is a stricter target that isn't achievable for all content.

    Normal text

    Any text smaller than the large text sizes, which usually means body copy, labels and captions.

    How it works

    The contrast ratio

    WCAG compares the relative luminance of the lighter color (L1) and the darker color (L2):

    (L1 + 0.05) / (L2 + 0.05)

    Results run from 1:1 for identical colors to 21:1 for black on white. They're cut off at two decimals, never rounded up, so a failing 4.499 can't read as 4.50. Pass or fail always uses the exact value.

    The suggestions

    For each threshold a pair misses, the calculator looks for the passing color closest in appearance to your foreground, using the OKLab color space. Hue and saturation shifts count for more than lightness shifts, and a gray always stays a pure gray.

    On mid-tone backgrounds no color can reach 7:1. When that happens, the calculator says so and names the strongest color available.
